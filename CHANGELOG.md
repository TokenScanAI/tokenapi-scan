# Changelog

All notable changes to the **public documentation** of TokenAPI Scan are recorded
here. Changes to the hosted detection service itself are announced on
<https://tokenscanai.com> and not tracked in this repo.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
versions follow [SemVer](https://semver.org/spec/v2.0.0.html).

## [0.2.0] — 2026-06-29

### Added
- Concise English + Chinese READMEs (`README.md`, `README.zh-CN.md`).
- `SECURITY.md` with private vulnerability reporting workflow.
- `docs/methodology.md` — what we detect and the high-level reasoning.
- `docs/data-fields.md` — public API field dictionary.
- `docs/independence.md` — third-party independence and conflict-of-interest
  policy.
- `.github/ISSUE_TEMPLATE/` — bug, feature, and security routing templates.

### Changed
- Repository scope narrowed from broad documentation dump to focused
  documentation in this repository only.
- Branding consolidated under the `TokenScanAI` GitHub organization.

### Removed
- Internal data-governance standards, build scripts, and SDK code — these
  belong to the hosted service and are not part of this documentation.

## [0.1.0] — 2026-05-23

### Added
- Initial public placeholder README, MIT license, and basic issue templates.
- Migrated from `haruki3rd/tokenscanai` to the `TokenScanAI` organization.
